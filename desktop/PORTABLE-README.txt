JavaScript-edu — Windows x64 portable (정확한 버전은 BUILD-INFO.json)

시작하기
1. ZIP 전체를 쓰기 가능한 일반 폴더에 해제하세요.
2. JavaScript-edu.exe를 실행하세요. 이 EXE만 다른 곳으로 옮기지 마세요.
3. Node.js 실습은 화면의 로컬 실행 범위를 읽고 동의한 뒤 시작하세요.

앱과 전체 Node.js 24.22.0이 포함되어 있어 Node.js/npm의 별도 설치가 필요 없습니다.
교재와 고정 실습 자료는 로컬에서 동작합니다. 외부 공식 문서 링크는 인터넷이 필요합니다.
학습자 Node.js 코드는 네트워크를 사용할 수 있습니다. OS 보안 샌드박스가 아닙니다.

대상: Windows x64, 공급자가 지원하는 Windows 10 서비스 채널 이상. Windows 11 권장.
Windows ARM64, macOS, Linux용 패키지가 아닙니다.
미서명 로컬 portable 패키지입니다. 코드 서명/SmartScreen 평판/스토어 게시를 완료하지 않았습니다.

학습 저장과 업데이트
초안·메모·진도·테마는 %APPDATA%\JavaScript-edu\browser 에 저장됩니다.
데스크톱 학습 주소는 %APPDATA%\JavaScript-edu\desktop-state.json 에 저장됩니다.
브라우저 개발 화면의 저장 데이터와는 별개이며 자동 이관하지 않습니다.
앱을 정상 종료한 뒤 새 버전 ZIP을 별도 폴더에 해제하면 같은 사용자 데이터로 이어갑니다.
설치 폴더를 이동해도 저장 위치와 학습 주소는 유지됩니다.
저장된 포트를 다른 앱이 사용하는 경우 해당 앱을 닫고 다시 시작하세요.
임의 포트로 바꿔 저장 데이터가 사라진 것처럼 보이게 하지 않습니다.
제거는 앱 종료 후 해제한 폴더만 삭제합니다. APPDATA 학습 데이터는 자동 삭제하지 않습니다.
별도 프로필이 필요하면 JS_EDU_USER_DATA_DIR 환경 변수에 새 절대 경로를 지정합니다.
기존 프로필의 origin별 데이터는 새 프로필로 자동 복사하지 않습니다.

보기 메뉴에서 확대/축소/실제 크기를 선택할 수 있습니다.
정상 종료 시 실행 중인 과제를 취소하고 포함 실행기를 정리합니다.
강제 프로세스 종료는 정상 종료와 다르며 Job Object 기반 전체 OS 자원 격리를 제공하지 않습니다.

BUILD-INFO.json: 소스 SHA, 정확한 포함 버전, 플랫폼과 미서명 상태
integrity/: 공급자 원본과 앱 소스의 파일 크기·SHA256 목록
THIRD-PARTY-NOTICES.txt: 공급자 라이선스 및 원본 고지 위치
ZIP 옆 .sha256 및 .manifest.json: 최종 ZIP과 실제 해제본 전체 대조 결과

# 학습 화면·용어집 시안

요청 범위는 **기획 + 작동하는 화면 시안**이다. 실제 교육 카탈로그·수업 개정·학습 저장·IDE·실행기·채점기는 변경하거나 연결하지 않는다. 개념 목차의 7개 항목은 화면 샘플이며 확정 강의 번호가 아니다. 클로저 화면은 기존 `bindings-and-closures` 초안을 바탕으로 작성했다.

## 로컬에서 보기

프로젝트 루트에서 다음 명령을 실행한 뒤 브라우저에서 <http://127.0.0.1:4178/>를 연다.

```powershell
node prototypes/learning-workspace/serve.mjs
```

종료는 `Ctrl+C`. 외부 패키지는 필요 없다. 서버는 `127.0.0.1`에만 바인딩하고 미리보기 HTML/CSS/JS 4개 파일만 제공한다. 현재 폴더 외 파일, README, 서버 코드, 실제 교육 데이터는 제공하지 않는다. ES 모듈을 사용하므로 파일 더블클릭의 `file://` 대신 HTTP로 연다.

## 확인할 동작

- 7개 개념 목차 선택과 5개 학습 단계 전환. 실제 학습 완료는 기록하지 않는다.
- 빈 검색은 현재 주제 관련 용어. 28개 시안 용어의 한글·영문·별명을 검색한다.
- 검색 우선순위는 완전 일치 → 접두 일치 → 부분 일치, 같은 점수는 한글 표제어 정렬이다. 대소문자·앞뒤 공백·Unicode NFKC를 정규화한다. 초성 검색과 설명 본문 검색은 제공하지 않는다.
- 한글 IME 조합 중에는 검색 결과·발표·Enter 동작을 보류한다. 조합 완료 후 갱신한다.
- 검색 결과와 보이는 개수는 즉시 바뀌며, 보조 기술용 결과 개수 발표는 입력이 250ms 안정된 뒤 갱신한다. 새 입력과 IME 조합 시작은 이전 발표 예약을 취소한다.
- 자세히 보기는 정의·직접 작성한 짧은 코드·오해·관련 주제·출처를 제공한다. 코드는 읽기 전용 설명이며 실제 실행 결과가 아니다.
- 큰 화면은 본문 옆 용어집과 상세 팝업, 중간 화면은 사전 drawer, 작은 화면은 전체 화면 sheet다. 화면 안에서 하나의 native dialog만 사용한다.
- 화면 폭이 줄어 초점이 있던 목차/사전 열을 접을 때 해당 상단 열기 버튼으로 초점을 이어 준다. 360px 이하의 도식 설명은 관계 행 아래로 배치한다.
- 작은 화면에서 상세를 닫으면 검색어·결과 스크롤·열었던 결과에 초점을 복원한다. 다시 Escape를 누르면 사전을 닫고 원래 버튼으로 돌아간다.
- 비조합 Escape가 브라우저의 검색어 지우기로 소비되지 않도록 한 단계 닫기를 처리한다. Tab·Shift+Tab은 현재 보이는 모달 내부의 포커스 요소에서 순환한다.
- 상세 URL은 `lesson`, `step`, `term`을 사용한다. 검색어 입력은 URL에 넣지 않는다. 브라우저 뒤로 가기·앞으로 가기로 화면과 상세를 복원한다.
- 단계 탭은 좌우 화살표·Home·End로 초점을 이동하고 Enter·Space로 선택한다. 좁은 화면은 탭을 줄바꿈하며 긴 코드는 코드 내부에서 가로로 스크롤한다.
- 코드 실행과 제출 검사 버튼은 연결 전 이유와 함께 비활성화한다.

## 파일

- `index.html`: 의미 구조와 공용 dialog.
- `styles.css`: 기술서의 색인·본문·주석을 활용한 반응형 레이아웃.
- `app.mjs`: 시안 목차·단계·검색·초점·URL 상태.
- `glossary-data.mjs`: `contentRevision:preview-1`, 개념 범위, 검색 별명과 출처를 갖춘 용어 샘플.
- `serve.mjs`: 로컬 전용 정적 파일 미리보기 서버.

코드의 동적 입력은 텍스트로 처리하며 검색어를 HTML로 해석하지 않는다. 실제 교재의 코드 파서·문법 강조 편집기는 연결 전이라 시안의 예제는 단색 고정폭 코드로 표시한다. 출처 링크는 추가 읽기 자료이며 모든 실행 환경 지원을 인증하는 표시가 아니다.

## 검증 범위

구현자는 Node 구문과 용어 데이터·검색 계약을 확인한다. 실제 브라우저 반응형·확대·키보드 검사, 독립 시각·코드 검토 결과는 부모 작업의 `docs/verification.md`에서 기록한다. OS IME와 실물 모바일 기기는 별도 확인 대상이다.

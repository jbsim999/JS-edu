> 이 문서는 첫 M5 커밋의 검증 기준선이다. 이후 원격 CI에서 발견한 실행 경계의 수정과 최신 Node 재검증은 [CI 보완 기록](runtime-ci-verification.md)을 따른다.

2026-10-19 최종 로컬 검증 기록. 선행 M4는 `10fa0d7a6dae4535a2265714a7b688e5f4a43743`으로 커밋·푸시했으며 [원격 CI](https://github.com/jbsim999/JS-edu/actions/runs/39184672700)가 성공했다. ## 범위와 실제 실행

공통32·브라우저8·Node8·통합4의52강과55개 실습을 연결한다. 통합 C02–C04는 하나의 강의 ID와 기존 브라우저 exerciseId를 유지하면서 Node 과제·5단계·선수 조건·퀴즈를 별도로 선택한다. languageVersion ES2026과 Node.js 호스트 버전24.22.0을 구분한다.

Windows x64의 고정 Node24.22.0 실제 로컬 HTTP 제공자에서 2026-10-19T02:12:33.218Z–02:13:47.014Z에 Node11과제 정답110/110·각11개 starter/대표 오답 거부·네이티브 예제11개 출력 일치·종료 정리를 확인했다. 제작자 프로세스는 Node22.17.0이고 실제 학습 코드 실행 파일은 고정24.22.0이다. 각 과제의 canonical module snapshot 지문·검사ID·검사 개정과 예제·readonly helper 원본87개를 대조해 `docs/execution/` 기록11개와 executionVerified:true를 연결했다. 환경 지문에는 실제 버전·플랫폼·아키텍처·정책·capability·grader 개정을 포함한다. 가용성은 현재 PC의 실제 실행 파일/버전으로 다시 확인한다.

## 독립 검토에서 수정한 경계

prepare/run은 grader를 읽지 않으며 runProbe를 필수로 한다. 채점기 누락을 주입한 실제 반례 뒤 준비/실행은 정상이고 submit만 실패하도록 수정했다. UI의 한 요청ID로 prepare→run/submit하는 계약은 snapshot 하나 아래 mode별 완료 cache로 맞췄다. 동일 제출 재전송은 재실행하지 않고 같은ID의 다른 코드는409다. Node 환경 지문은 Worker capability와 graderRevision을 포함해 서로 다른 검사 개정의 성공을 현재 성취로 저장하지 않는다.

최종 독립 검토에서 정리 실패에도 정상 성취로 인정되는 경로와 Node 종료 오류가 다른 자원 정리를 중단하는 경로를 발견·수정했다. 준비/제출의 정리 경고는 infrastructure-error이며, 공통 성취 판정도 기존 저장 결과의 cleanupWarning/cleanupPending을 거부한다. 준비 정리 실패는 후속 채점으로 넘어가지 않는다. DELETE의 정리 경고는 클라이언트와 현재 UI 세대에 전달한다. 서버 종료는 Node 정리 실패에도 브라우저 포트와 모듈 만료 타이머를 닫고 callback(error)를 전달한다.

실제 파일 삭제 EACCES를 주입한 준비·제출·취소·서버 종료와 화면 상태 전이7회귀 PASS를 확인했고, 원복 후 정상 제출로 복구했다. 정리 경고가 있는 과거 success를 저장 성취로 재사용하지 않는다. 프런트 필터가 resolved host entry 대신 catalog base entry를 사용하도록 수정해 C02 Node에서 Node 경로를 선택해도 현재 강의를 유지한다. 작성자와 별도인 코드 리뷰어가 실제 diff·검사 로그·지문을 읽기 전용으로 대조하고 수정 경로 및 최종 소스 정합성 PASS를 판정했다. 리뷰어가 테스트를 직접 실행하거나 인간 GitHub 승인을 했다는 뜻은 아니다.

## 화면과 기록

별도 Chrome QA 포트에서 N01 환경 확인의 미import·동의 전 차단·starter0/8·정답 run/submit8/8·취소·수정 무효화와 C02 브라우저9/9↔Node10/10을 실제 확인했다. 호스트별 코드·퀴즈·제출, 공유 메모, 뒤/앞·재로드, 동의 해제, 두 호스트 완료 후1/52 중복 방지, 실행 중 빠른 호스트 전환의 늦은 결과 차단을 확인했다. OS/아키텍처 지문 변경 뒤 이전 통과가 무효화되고 새 제출로 복구했다. Node22.17.0에서는 버전 불일치 이유와 실행·동의 차단을 확인했다.

실제 합성 화면은 승인된 피스타치오 효과·밝은/어두운 테마를 유지한다. 320/360/390/768/1440·1280×420·640×360 뷰포트, 파일 탭 End/Enter·읽기 전용·목차 마지막 항목과 Escape 초점 복귀를 확인했다. 총괄이 실제 모바일·데스크톱·짧은 높이·밝은 테마 PNG를 직접 검토했다. 이는 브라우저 에뮬레이션이며 실제 기기나 실제200% 확대 검사가 아니다.

## 한계와 패키징

공개 자가 학습 검사이며 성적 인증이 아니다. Node Permission Model은 OS 샌드박스가 아니고 네트워크·기존 파일 디스크립터·링크 접근 전체를 격리하지 않는다. N07의 하위 Worker에는 권한 이탈 가능성이 있고64MB는 JS 힙 설정이며 전체 RAM 상한이 아니다. [실행 계약](node-runtime-contract.md)의 고지를 유지한다. 실제 기기·실제200% 확대·OS IME·스크린리더와 설치본은 미검증이다.

공식 전체 Windows 배포본은 개발 검증에 사용하며 출처/체크섬/라이선스는 `runtime/node-vendor.json`을 따른다. M5는 Node 고정24.22.0의 Windows/Ubuntu 별도 실행 CI를 추가한다. 커밋별 원격 실행 결과는 GitHub Actions를 따른다. 설치·압축 패키징, 서명, 배포, main 병합은 수행하지 않았다.

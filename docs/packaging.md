# 추후 데스크톱 패키징

현재 설치형 셸·패키지·포함 런타임은 없다. 패키징 요청이 들어오면 **junbo-desktop-runtime-packaging** 스킬을 읽고 적용한다.

대상 OS/CPU/최소 OS, 제품 소스 SHA, 포함/외부 도구, 정확한 런타임 버전·공식 배포본·checksum·고지/라이선스 조건부터 확정한다. 전체 vendor 배포본과 manifest를 보존하고 stage → 빌드 → 서명 → 최종 ZIP 해제/실제 설치 상태를 비교한다. Windows 검증을 macOS 검증으로 대체하지 않는다.

출시할 최종 앱에서 실제 코드 실행·제출·취소·초안/진도 복원·재시작과 경로 이동을 검증한다. 기존 앱과 사용자 데이터는 보존한다. 미실행·미서명·미공증·미게시를 구분한다. 현재 기록은 앞으로의 작업 계약이며 패키징 PASS나 게시 권한이 아니다.

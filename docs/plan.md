# 제품 기획

상태: 초기 구조 / 설계 초안. 이번 범위는 프로젝트 연결과 저장소 준비다.

대상은 다른 언어 경험자와 현직자다. JavaScript의 바인딩·동적 타입·프로토타입·함수·비동기·모듈·호스트 경계를 설명하고 코드 해석·결함 수정·설계 이유로 진단한다.

제품은 웹 교재와 공유 가능한 저장/실행 어댑터 경계부터 설계한다. UI 프레임워크·편집기·호스팅·데스크톱 셸·제품 런타임은 아직 선정하지 않았다. 설치형은 후속 단계의 선택이다.

학습 흐름은 이론 → 예시 → 문제풀이 → 실무 심화 → 직접 코딩이다. 퀴즈·실행·제출·설계 메모·환경 준비는 별도 상태이며 단순 방문이나 준비 성공을 완료로 집계하지 않는다. 과거 결과는 수업 개정과 코드/환경 snapshot에 연결한다.

언어 기준 ES2026와 실제 브라우저/Node.js 버전을 별도 관리한다. 특정 Node.js 버전이 정식판 전체를 지원한다고 추론하지 않는다. 취업 공고나 실제 기업 과제에 기반했다는 주장은 하지 않는다.

수용 조건: 데이터 연결 구조 PASS, 명시적인 실행 불가, 초기 GitHub origin과 main 동기화, 독립 리뷰, 다음 구현 의존성 기록. 전체 제품 완료 조건은 대표 수업의 내용/실제 정답·오답 검사/초안 저장/개정/입력/합성 화면 검증 후 별도로 승인한다.

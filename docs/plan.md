# 제품 기획

상태: 초기 구조 / 상세 기획 검토 단계. 2026-10-14 후속 요청으로 공식 근거를 조사해 강의 로드맵을 구체화하고 GitHub 저장소를 공개로 전환했다. 제품 기능 구현은 기획 검토 뒤 이어간다.

대상은 다른 언어 경험자와 현직자다. JavaScript의 바인딩·동적 타입·프로토타입·함수·비동기·모듈·호스트 경계를 설명하고 코드 해석·결함 수정·설계 이유로 진단한다.

교육 범위는 공통 언어 32강, 브라우저 8강 또는 Node.js 8강, 통합 프로젝트·검증 4강이다. 한 경로 44강, 양쪽 트랙 52강이며 확장 선택 과정은 별도다. 단원별 목표·실습·핵심 통과 조건·선수 관계·공식 출처·제품 구현 관문은 [상세 로드맵](roadmap.md)을 따른다. 현재 카탈로그의 수업 1개와 계획 강의 수를 구분한다.

후속 이용자 요청의 데이터 타입·실행 컨텍스트·this·콜백·클로저·프로토타입·클래스 7장, 상위/하위/정리 71개 항목은 기존 32강의 하위 절과 실습으로 보강한다. [항목 대조표](requested-topics-audit.md)에서 기존 상태와 연결 수업을 확인한다. 기존 카운터 과제 계약은 보존하고 메모리/리스너·커링 등 추가 행동은 별도 후속 과제로 둔다.

학습 화면은 절제된 기술서 형태의 목차·본문·보조 사전으로 설계한다. 사이드 용어집에서 한영/별명 검색 → 간단 설명 → 상세 팝업 → 읽던 위치 복귀를 제공한다. 좁은 화면은 사전 시트 안에서 검색과 상세를 전환한다. 구체적 시각·검색·포커스·URL·반응형 계약은 [UI/UX 기획](ui-ux-plan.md)을 따른다.

이번 사용자 선택은 기획과 작동하는 화면 시안이다. [시안](../prototypes/learning-workspace/index.html)은 제품 교재·저장·진도·runner 미연결의 별도 미리보기이며 기술 선정/실제 학습 제품 완성을 뜻하지 않는다. 검색과 상세 열람은 학습 제출 통과나 성취를 생성하지 않는다.

제품은 웹 교재와 공유 가능한 저장/실행 어댑터 경계부터 설계한다. UI 프레임워크·편집기·호스팅·데스크톱 셸·제품 런타임은 아직 선정하지 않았다. 설치형은 후속 단계의 선택이다.

학습 흐름은 이론 → 예시 → 문제풀이 → 실무 심화 → 직접 코딩이다. 퀴즈·실행·제출·설계 메모·환경 준비는 별도 상태이며 단순 방문이나 준비 성공을 완료로 집계하지 않는다. 과거 결과는 수업 개정과 코드/환경 snapshot에 연결한다.

언어 기준 ES2026와 실제 브라우저/Node.js 버전을 별도 관리한다. 특정 Node.js 버전이 정식판 전체를 지원한다고 추론하지 않는다. 취업 공고나 실제 기업 과제에 기반했다는 주장은 하지 않는다.

초기 골격 수용 조건: 데이터 연결 구조 PASS, 명시적인 실행 불가, 초기 GitHub origin과 main 동기화, 독립 리뷰, 다음 구현 의존성 기록. 이 조건은 기존 골격 검사 범위다.

제품 구현은 기존 클로저 수업 하나의 내용·기준 답안·대표 오답·실제 실행/제출·편집·저장/복원·개정·입력·합성 화면을 먼저 검증한 뒤 공통 과정으로 확장한다. 웹 우선 경로를 완성하고 Node 실행 제공자와 별도 트랙을 이어간다. Node 24 LTS는 실행 후보이며 정확한 버전·호환성은 첫 실행기 검증 때 고정한다.

평가는 자가 학습용 행동 검증이다. 공개 저장소와 브라우저에 전달된 검사 자료를 비밀 채점 또는 위변조 방지 성적 인증으로 표현하지 않는다. 원격 불특정 제출·공인 성적은 별도 신뢰 경계 설계가 필요하다. 공개 저장소 전환은 웹 배포·문서 푸시·라이선스 지정과 별도다.

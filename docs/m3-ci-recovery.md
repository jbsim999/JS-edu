# M3 CI 호환성 수정

M3 커밋 `682a96cab7b4cc9131c38ff8531a9bdf6819c1ae`는 로컬 Windows 검사와 실제 브라우저 검수를 통과했지만 [원격 CI](https://github.com/jbsim999/JS-edu/actions/runs/38718480912)의 Linux Node 24 검사에서 실패했다. 제작자 검증기가 `process.execArgv`의 전체 프로세스 옵션을 Worker에 재전달했고, 해당 Node 환경에서 Worker에 허용되지 않는 옵션이 포함됐다.

신뢰하는 고정 저자 소스를 실행하는 두 제작자 Worker는 부모 옵션을 상속하지 않도록 `execArgv: []`로 고정했다. 기존 시간·출력·힙 설정과 관찰 계약은 유지했다. 모듈 eval에서 Worker 비허용 옵션 두 개를 추가한 뒤 검증기를 불러오는 회귀를 보강했다.

실제 고정 Node 24.22.0에서 관련 검사 84/84 PASS. 수정 세 파일만 포함한 분리 검사본 `work/m3-ci-review/`는 Windows Node 22.17.0에서 `npm run check` PASS: 구문170·테스트167/167·정답264/264·예제32/32·skip0. 독립 정적 검토도 PASS다. 원격 결과는 후속 확인한다.

후속 호스트 강의를 위해 제작자 CLI에 명시적인 `--allow-host-skips` 옵션을 추가했다. 기본 동작은 엄격하며, 이 옵션도 실제 정답/예제 실패와 실행기 미정의를 숨기지 않는다. 호스트 전용 검사는 결과를 PARTIAL과 실제 호스트 검사 필요로 표시한 채 명령 종료만 허용한다. 이 옵션은 DOM/Node 과제 실행 완료의 근거가 아니다. 실제 호스트 검증은 별도 필수 게이트다.

기존 M3 소스 snapshot은 원래 커밋의 기록이며 이 수정 후 현재 소스 전체의 해시라고 사용하지 않는다. 패키징·병합·배포는 수행하지 않았다.

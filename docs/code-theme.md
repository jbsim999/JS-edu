# 코드 문법 테마

예시 코드, 용어집의 짧은 코드, 직접 코딩의 본문·모듈 파일·읽기 전용 선언, 실행 결과의 구조화한 값에 같은 문법 색상을 적용한다. JavaScript(.js/.mjs/.cjs), JSON, HTML/XML, CSS를 구분한다. 실행 로그와 일반 설명은 원문 그대로 표시한다.

피스타치오 배경에 맞춰 밝은 화면은 자주색 키워드·초록 문자열·파란 함수·갈색 숫자, 다크 모드는 연보라·연두·하늘색·살구색을 사용한다. 두 배경에서 텍스트 명암비 4.5:1 이상을 검사한다. 고대비 모드에서는 시스템 글자색과 native 편집 문자 표시를 사용한다.

Prism 1.30.0의 공식 core/markup/css/clike/javascript/json 구성 요소를 변경 없이 연결하고, 외부 전역·자동 DOM 탐색·Worker 메시지 수신·네트워크 플러그인 없이 토큰 API만 노출하는 모듈로 묶었다. [공식 API](https://prismjs.com/docs/prism), [토큰 정의](https://prismjs.com/tokens.html)를 기준으로 한다. `web/vendor/prism/`에 MIT 라이선스와 구성 요소별 원본 URL/SHA256 및 최종 번들 SHA256을 보관한다. CDN과 추가 npm 설치에 의존하지 않는다. 문법 토큰 색상이며, 변수 타입 추론이나 언어 서버의 의미 분석을 제공하지 않는다. 기본 HTML 인코더의 NBSP 정규화를 피하도록 토큰을 원문 보존 방식으로 안전하게 직렬화한다.

입력은 기존 textarea가 담당한다. 문법 색상은 `aria-hidden`·선택 불가 레이어에만 표시하며 값·선택·undo·Tab 이동·초안 키·제출 fingerprint를 변경하지 않는다. 가로/세로 스크롤과 글꼴·줄높이·리사이즈를 동기화한다. 조합 입력 중에는 native 글자를 보이고 조합이 끝난 뒤 다시 색상을 갱신한다. 화면/파일을 바꿀 때 observer와 이벤트를 해제한다. 20,000자를 초과하거나 지원하지 않는 파일은 HTML로 해석하지 않는 기본 문자 표시로 전환하며 입력·저장·제출은 유지한다.

개별 회귀5개는 문법·원문 복원·HTML 주입 방지·긴/미완성 코드·공급자 지문/고지·명암비를 검사한다. 별도 Chrome155 프로필의 `artifacts/code-theme-qa/report.json`에서 예시/입력·선택/테마·원본 카운터7조건 제출·한글 초안 복원·긴 줄/양방향 스크롤·Tab·320/360/390/768/1440과 짧은 창·고대비·모듈파일/JSON·용어집·특수 공백 원문 보존11묶음을 실제 확인했다. 총괄이 밝은/어두운 편집기 합성 화면을 검토했다. 브라우저 크기 에뮬레이션을 물리 모바일 검사로, 한글 문자열 입력을 OS IME 검사로 표현하지 않는다. 실제 패키지·각 OS 검증은 해당 최종 패키지 기록을 따른다.

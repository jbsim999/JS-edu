# JavaScript-edu

다른 언어 경험자와 현직 개발자가 JavaScript의 의미 모델부터 실무 설계까지 학습하는 교육 프로젝트입니다.

확정 로드맵의 **52강·다섯 학습 단계·55개 실습**을 제공합니다. 공통32·브라우저8·Node.js8·통합4강이며, 통합 C02–C04는 브라우저와 Node 실습을 선택합니다. 승인한 피스타치오 스타일·다크 모드와 82개 검색형 용어집을 유지하면서 실제 실행·471개 행동 검사·중지·제공자별 시간 제한을 연결했습니다. 퀴즈, 코딩 통과, 설계 메모 자가 확인은 따로 기록합니다.

예제·용어집·코드 편집기에는 밝은/어두운 화면에 맞춘 문법 색상을 적용합니다. 키워드·문자열·함수·숫자·주석을 구분하며 인터넷 연결 없이 작동합니다. [코드 테마와 검증 범위](docs/code-theme.md)를 확인하세요.

## 데스크톱 앱으로 학습하기

Windows x64용 포터블 ZIP을 **폴더 전체로 압축 해제**한 뒤 `JavaScript-edu.exe`를 실행합니다. 포함된 런타임을 사용하므로 Node.js를 별도로 설치할 필요가 없습니다. EXE만 다른 폴더로 옮기면 실행할 수 없습니다. 앱 메뉴의 보기에서 확대·축소할 수 있습니다.

macOS용은 Intel(x64)과 Apple Silicon(arm64)을 구분합니다. 해당 ZIP을 전체 해제해 `JavaScript-edu.app`을 실행하며, 앱 내부 파일을 분리하지 않습니다. 포함 Node.js의 최소 조건에 따라 macOS13.5 이상을 대상으로 합니다. 앱 wrapper는 미서명·미공증이며, CPU별 실제 실행 및 최종 산출물 검증 상태는 [현재 상태](docs/project-state.md)를 확인하세요.

초안·메모·진도는 사용자별 앱 데이터에 저장합니다. 앱 폴더를 옮기거나 새 버전으로 교체해도 사용자 데이터 폴더를 보존하세요. 웹 브라우저판의 기존 기록을 앱으로 자동 이전하지는 않습니다. Node 실습은 앱에서도 최초 실행 동의가 필요합니다.

패키지는 로컬 검증 산출물이며 공개 다운로드 릴리스는 아직 게시하지 않았습니다. 앱 자체 코드 서명은 제공하지 않습니다. 실제 빌드·검증 범위와 파일 식별자는 [패키징 기록](docs/packaging.md)을 확인하세요.

## 프로젝트 연결

이 README가 있는 **JS-edu 폴더**를 Codex 프로젝트로 연결하세요. 이어서 [현재 상태](docs/project-state.md)에서 구현 범위와 실제 검증 결과를 확인합니다.

정식 제품 표시명은 JavaScript-edu입니다. 현재 로컬 폴더명과 GitHub 저장소명은 JS-edu, npm 내부 식별자는 js-edu를 유지합니다. 원격 주소는 https://github.com/jbsim999/JS-edu 이며 실제 연결 상태는 현재 상태 문서와 Git 설정을 확인하세요.

## 개발자 빠른 시작

Node.js 22 이상에서 실행합니다. 외부 npm 의존성이 없어 별도 설치 없이 학습 화면을 시작할 수 있습니다.

```sh
npm run dev
```

[로컬 학습 화면](http://127.0.0.1:4179/)을 엽니다. 서버는 이 PC에서만 접근하도록 구성했습니다. 52강의 다섯 단계·예제·퀴즈·직접 코딩을 제공합니다. 통합 강의의 두 호스트를 모두 공부해도 완료 강의 수는 중복 집계하지 않습니다. 코드·메모·화면 설정·자가 학습 상태는 이 브라우저에 저장하며 기기 간 동기화는 제공하지 않습니다. 저장 실패는 화면에 알립니다.

Node 실습에는 **정확히 Node.js 24.22.0**이 필요합니다. 이 버전으로 개발 서버를 시작하면 같은 실행 파일을 사용합니다. 서버를 다른 버전으로 시작할 때는 `JS_EDU_NODE_EXECUTABLE`에 설치한 고정 실행 파일의 경로를 지정하세요. 상대 경로도 프로젝트 폴더를 기준으로 사용할 수 있습니다.

```powershell
# 설치한 공식 배포본 경로로 변경하세요. 시스템 PATH는 바꾸지 않습니다.
$env:JS_EDU_NODE_EXECUTABLE = 'C:\tools\node-v24.22.0-win-x64\node.exe'
npm run dev
```

공식 배포본의 출처·체크섬은 [공급자 기록](runtime/node-vendor.json)을 따릅니다. 바이너리는 Git에 포함하지 않습니다. 실행 파일이 없거나 버전이 다르면 Node 실행 불가 이유를 표시하며 교재·퀴즈·편집은 이용할 수 있습니다. Node 실행과 제출은 화면의 로컬 코드 실행 동의가 필요합니다. 권한·네트워크·메모리 제한의 범위는 [Node 실행 계약](docs/node-runtime-contract.md)을 확인하세요.

기본 검사는 다음과 같습니다.

```sh
npm run check
```

이 명령은 교재 연결 구조·JavaScript 구문·실행/상태/서버 회귀와 공통 정답·오답·TODO·예제의 행동을 확인합니다. 일반 제작자 검사에서 DOM/Node 호스트 과제 생략은 PARTIAL입니다. 브라우저 전수 검증과 고정 Node 제공자 검증은 별도 근거이며 ES2026 전체 지원 인증은 아닙니다. 제작자 명령은 신뢰하는 저장소 소스만 실행합니다.

```sh
npm run check:node
```

이 명령은 고정 Node 실행 파일을 사용해 Node8강과 선택 통합3과제의 정답·starter·대표 오답·네이티브 예제 출력·정리를 확인합니다. 대상 버전이 없으면 실패하며 다른 버전의 결과로 대체하지 않습니다. 기본 개발·회귀 검사 환경과 제품의 Node24.22.0 실습 런타임은 구분합니다.

제작자 전용 브라우저 검증은 `node web/serve.mjs --port 4182 --qualification`로 별도 서버를 시작하고 `/execution/qualification.html`을 엽니다. 이 모드에서만 고정 정답·대표 오답 경로를 제공합니다. 기본 학습 서버에는 이 경로가 없습니다.

## 학습 설계

언어 기준은 ECMAScript 2026(ECMA-262 제17판)입니다. [공식 표준](https://262.ecma-international.org/17.0/)과 [교육 로드맵](docs/roadmap.md)을 기준으로 이론 → 예시 → 문제풀이 → 실무 심화 → 직접 코딩의 다섯 단계를 구성합니다. 브라우저 API와 Node.js API는 언어 표준과 분리합니다.

대표 수업은 바인딩·스코프·클로저입니다. 실제 브라우저 정답/오답·제한 동작 검증 근거는 [실행 증거](docs/execution/independent-counter.json)에 기록합니다. 실제 실행 검증을 완료한 과제만 executionVerified:true로 표시합니다. 공개 행동 검사는 자가 학습용이며 공인 성적이나 완전한 보안 격리가 아닙니다. Worker에는 절대 메모리 상한이 없고 같은 출처의 저장소 권한이 남을 수 있습니다.

# JavaScript-edu

다른 언어 경험자와 현직 개발자가 JavaScript의 의미 모델부터 실무 설계까지 학습하는 교육 프로젝트입니다.

현재는 **실제 실행·자동 채점 연결 단계**입니다. 승인한 피스타치오 스타일과 검색형 용어집을 유지하면서, 공통 01–11강의 함수 본문 실행·82개 행동 검사·중지·시간 제한을 연결했습니다. 퀴즈, 코딩 통과, 설계 메모 자가 확인은 따로 기록합니다. 나머지 강의는 확정 로드맵 순서로 연결하며 설치 패키징은 전체 검증 뒤 마지막 한 번으로 미룹니다.

## 프로젝트 연결

이 README가 있는 **JS-edu 폴더**를 Codex 프로젝트로 연결하세요. 이어서 [현재 상태](docs/project-state.md)에서 구현 범위와 실제 검증 결과를 확인합니다.

정식 제품 표시명은 JavaScript-edu입니다. 현재 로컬 폴더명과 GitHub 저장소명은 JS-edu, npm 내부 식별자는 js-edu를 유지합니다. 원격 주소는 https://github.com/jbsim999/JS-edu 이며 실제 연결 상태는 현재 상태 문서와 Git 설정을 확인하세요.

## 개발자 빠른 시작

Node.js 22 이상에서 실행합니다. 외부 npm 의존성이 없어 별도 설치 없이 학습 화면을 시작할 수 있습니다.

```sh
npm run dev
```

[로컬 학습 화면](http://127.0.0.1:4179/)을 엽니다. 서버는 이 PC에서만 접근하도록 구성했습니다. 목차는 전체 52강의 계획과 실제 제공 강의를 구분합니다. 현재 공통 01–11강의 다섯 단계·예제·퀴즈·직접 코딩을 제공합니다. 코드·메모·화면 설정·자가 학습 상태는 이 브라우저에 저장하며 기기 간 동기화는 제공하지 않습니다. 저장 실패는 화면에 알립니다.

기본 검사는 다음과 같습니다.

```sh
npm run check
```

이 명령은 교재 연결 구조·JavaScript 구문·실행/상태/서버 회귀와 제작자가 작성한 정답·오답·TODO·예제의 실제 행동을 확인합니다. 제작자 검사는 신뢰하는 저장소 소스만 Node Worker에서 실행하며 HTTP 제출 코드를 서버에서 실행하지 않습니다. 브라우저의 실제 실행/CSP 검수와 ES2026 전체 지원 인증은 별개입니다. 개발 확인 환경은 Node.js 22.17.0이고 학습 코드는 화면에 표시되는 실제 브라우저 엔진에서 실행합니다.

제작자 전용 브라우저 검증은 `node web/serve.mjs --port 4182 --qualification`로 별도 서버를 시작하고 `/execution/qualification.html`을 엽니다. 이 모드에서만 고정 정답·대표 오답 경로를 제공합니다. 기본 학습 서버에는 이 경로가 없습니다.

## 학습 설계

언어 기준은 ECMAScript 2026(ECMA-262 제17판)입니다. [공식 표준](https://262.ecma-international.org/17.0/)과 [교육 로드맵](docs/roadmap.md)을 기준으로 이론 → 예시 → 문제풀이 → 실무 심화 → 직접 코딩의 다섯 단계를 구성합니다. 브라우저 API와 Node.js API는 언어 표준과 분리합니다.

대표 수업은 바인딩·스코프·클로저입니다. 실제 브라우저 정답/오답·제한 동작 검증 근거는 [실행 증거](docs/execution/independent-counter.json)에 기록합니다. 실제 실행 검증을 완료한 과제만 executionVerified:true로 표시합니다. 공개 행동 검사는 자가 학습용이며 공인 성적이나 완전한 보안 격리가 아닙니다. Worker에는 절대 메모리 상한이 없고 같은 출처의 저장소 권한이 남을 수 있습니다.

## 구조

| 경로 | 책임 |
| --- | --- |
| curriculum/ | 수업 카탈로그·단원·예제·과제 |
| starter/ | 학습자가 편집할 코드 |
| reference/ | 제작자 기준 답안·대표 오답 (기본 서버 비공개) |
| curriculum/checks/ · grader/ | 고정 관찰 검사·계약 |
| runtime/ | 버전별 실행 프로필과 호스트 계약 |
| web/ | 학습 화면·용어집·개정별 저장·로컬 서버·브라우저 실행기 |
| desktop/ | 추후 설치형 앱 연결 경계 |
| scripts/ · tests/ | 구조 검사·구문 검사·어댑터 테스트 |
| .github/ | CI 및 PR 템플릿 |
| docs/ | 기획·로드맵·검증·인계·패키징 |

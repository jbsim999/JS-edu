# JavaScript-edu

다른 언어 경험자와 현직 개발자가 JavaScript의 의미 모델부터 실무 설계까지 학습하는 교육 프로젝트입니다.

현재는 **학습 화면의 첫 구현 단계**입니다. 승인한 피스타치오 스타일, 라이트·다크 모드, 반사광·그림자·반투명 효과와 검색형 용어집을 적용했습니다. 대표 클로저 초안의 다섯 단계, 함수 본문 편집, 이 브라우저의 초안·메모 저장을 제공합니다. 실제 코드 실행·자동 채점·완성 IDE·설치 패키지는 아직 제공하지 않습니다.

## 프로젝트 연결

이 README가 있는 **JS-edu 폴더**를 Codex 프로젝트로 연결하세요. 이어서 [현재 상태](docs/project-state.md)에서 구현 범위와 실제 검증 결과를 확인합니다.

정식 제품 표시명은 JavaScript-edu입니다. 현재 로컬 폴더명과 GitHub 저장소명은 JS-edu, npm 내부 식별자는 js-edu를 유지합니다. 원격 주소는 https://github.com/jbsim999/JS-edu 이며 실제 연결 상태는 현재 상태 문서와 Git 설정을 확인하세요.

## 개발자 빠른 시작

Node.js 22 이상에서 실행합니다. 외부 npm 의존성이 없어 별도 설치 없이 학습 화면을 시작할 수 있습니다.

```sh
npm run dev
```

[로컬 학습 화면](http://127.0.0.1:4179/)을 엽니다. 서버는 이 PC에서만 접근하도록 구성했습니다. 목차의 클로저는 실제 교재 초안과 연결되고, 나머지 여섯 개념은 미리보기입니다. 코드·메모·화면 설정은 이 브라우저에 저장되며 기기 간 동기화와 학습 완료 집계는 제공하지 않습니다. 저장 실패는 화면에 알립니다.

기본 검사는 다음과 같습니다.

```sh
npm run check
```

이 명령은 교재 연결 구조·JavaScript 구문·기본 어댑터 동작을 확인합니다. 수업 제출 통과·ES2026 전체 지원·제품 실행을 뜻하지 않습니다. 현재 개발 확인 환경은 Node.js 22.17.0입니다. 제품 런타임은 미선정이며 개발 도구 버전과 별도입니다.

## 학습 설계

언어 기준은 ECMAScript 2026(ECMA-262 제17판)입니다. [공식 표준](https://262.ecma-international.org/17.0/)과 [교육 로드맵](docs/roadmap.md)을 기준으로 이론 → 예시 → 문제풀이 → 실무 심화 → 직접 코딩의 다섯 단계를 구성합니다. 브라우저 API와 Node.js API는 언어 표준과 분리합니다.

대표 초안은 바인딩·스코프·클로저입니다. 교재 검수·대표 정답/오답 실행·학습자 흐름 검증을 완료한 뒤 카탈로그를 확장합니다. 실행 프로필은 available:false, 과제는 executionVerified:false입니다.

## 구조

| --- | --- |
| curriculum/ | 수업 카탈로그·단원·예제·과제 |
| starter/ | 학습자가 편집할 코드 |
| reference/ | 이후 작성할 기준 답안 |
| grader/ | 고정 행동 검사 계약 |
| runtime/ | 버전별 실행 프로필과 호스트 계약 |
| web/ | 학습 화면·검색형 용어집·초안/메모 저장·로컬 서버·실행 불가 어댑터 |

| scripts/ · tests/ | 구조 검사·구문 검사·어댑터 테스트 |
| .github/ | CI 및 PR 템플릿 |
| docs/ | 기획·로드맵·검증·인계·패키징 |
